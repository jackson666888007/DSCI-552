# Homework 4

This homework includes Questions 2, 3, and 4.
It uses feature extraction code from Homework 3.

## Files

- HW4.ipynb has my code, results, and answers.
- requirements.txt lists the packages needed to run the code.
- ../Homework3/data/AReM has the data.

Keep Homework3 and Homework4 in the same main folder.

## Methods

- Logistic regression with RFE
- Logistic regression with L1 regularization
- Case-control sampling
- Multinomial logistic regression
- Gaussian and Multinomial Naive Bayes

## Run the notebook

1. Open a terminal in the Homework4 folder.
2. Use a Python environment with the required packages.
3. Run: python -m pip install -r requirements.txt
4. Run: python -m notebook
5. Open HW4.ipynb.
6. Restart the kernel and run all cells.
7. Wait for all cells to finish, then save the notebook.

The model search may take several minutes.
