# DSCI 552 - Homework 8

## What I Did

I compared supervised SVM, semi-supervised SVM, K-means, and spectral clustering on breast cancer data. I also compared active and passive learning with an L1 SVM on banknote data.

## Files

- `HW8.ipynb` has the code, results, plots, and written answers.
- `data/` has the two datasets and the breast cancer data notes.
- `requirements.txt` lists the Python packages I used.

## How to Run

I used Python 3.13. Open a terminal in the `Homework8` folder.

1. Run `python -m pip install -r requirements.txt`.
2. Run `python -m jupyterlab`.
3. Open `HW8.ipynb`, restart the kernel, and run all cells in order.

The full notebook takes a few minutes to run.
